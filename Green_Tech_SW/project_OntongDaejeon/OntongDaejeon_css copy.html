온통대전

온통대전은 대전광역시에서 제공하는 공공데이터 포털입니다.

온통대전 공공데이터

온통대전에서 제공하는 공공데이터는 다음과 같습니다.

  • 대전시 공공데이터 포털
  • 대전시 열린데이터 광장
  • 대전시 빅데이터 캠퍼스
  • 대전시 교통정보센터
  • 대전시 문화관광
  • 대전시 환경정보
  • 대전시 복지정보
  • 대전시 교육정보
  • 대전시 건강정보
  • 대전시 안전정보

이 외에도 다양한 공공데이터를 제공하고 있습니다.



온통대전 이용 방법

온통대전은 누구나 무료로 이용할 수 있습니다. 이용 방법은 다음과 같습니다.

  1. 온통대전 홈페이지 접속
  2. 회원가입 또는 비회원으로 이용
  3. 원하는 공공데이터 검색
  4. 데이터 다운로드 또는 API 활용

자세한 이용 방법은 온통대전 홈페이지를 참고하시기 바랍니다.
